# 🚀 Rumbo a la Certificacion Cisco DevNet Associate (DEVASC 200-901)

Repositorio enfocado en la preparacion tecnica desarrollo de scripts y documentacion practica para obtener la certificacion **Cisco Certified DevNet Associate (DEVASC 200-901)**.

---

## 📌 Metodologia y Estructura

El aprendizaje y el codigo de este repositorio se basan de forma estricta en la guia de estudio oficial:
📖 **_Cisco Certified DevNet Associate DEVASC 200-901 Official Cert Guide_**

Para mantener un orden directo con la temaria del examen **cada subcarpeta del repositorio corresponde a un capitulo del libro oficial** reuniendo laboratorios scripts de automatizacion y notas de estudio correspondientes.
